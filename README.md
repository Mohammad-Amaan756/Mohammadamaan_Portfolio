# Amir Khushroo — Portfolio

A responsive, single-page portfolio built with React, Vite, Tailwind CSS v4, and Lucide icons. Visual direction: editorial, asymmetric layout; near-black canvas; lime accent; custom AR monogram; subtle grid and motion.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL Vite prints (typically http://localhost:5173).
5. Check a production build with `npm run build` and preview with `npm run preview`.

## Personalize before publishing

- Verify the project descriptions and mark unfinished work accurately.
- Add repository/demo URLs to the project cards if available.
- Add internship dates and concrete contributions.
- Add a resume PDF to `public/` and wire up a download link if desired.
- Confirm the GitHub, LinkedIn, and email details are correct.

## Deploy

Push the project to GitHub and import the repository into Vercel. Vercel detects Vite automatically; use `npm run build` as the build command and `dist` as the output directory.
